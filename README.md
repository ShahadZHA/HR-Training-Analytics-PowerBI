# HR-Training-Analytics-PowerBI
Power BI dashboard analyzing HR training outcomes, costs, performance, and employee satisfaction using a star schema model.

## Key Metrics
- *2,845* employees analyzed
- *1.59M* total training cost
- *3.03* average satisfaction score

## Dashboard Insights
- *Training Outcome Distribution:* Completed, Incomplete, Passed, Failed
- *Average Satisfaction by Department:* Sales leads (3.14); Admin Offices lowest (2.51)
- *Performance Score by Training Program:* Exceeds / Fully Meets / Needs Improvement / PIP
- *Training Cost by Program:* Communication, Project Management, Customer Service, Leadership, Technical Skills
- *Workforce Satisfaction:* Active vs. Terminated employees
- *Filters:* Month and Age slicers

## Data Model
Star schema:
- *Fact table:* FACT HR
- *Dimensions:* DIM Employee, DIM Location, DIM Date, DIM Training
- *DAX measure:* Average Satisfaction

## Tools
Power BI, DAX, Power Query, Data Modeling
